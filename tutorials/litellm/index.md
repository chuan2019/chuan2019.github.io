A hands-on tutorial for [LiteLLM](https://github.com/BerriAI/litellm), the Python SDK and the proxy, in 23 sections. Each section is one practical use case with a runnable script, the script's real output, and exercises.

LiteLLM changes quickly, so the tutorial comes in editions. Each edition is written for, and verified against, one LiteLLM release. Pick the one that matches the LiteLLM you run.

The code is in [chuan2019/litellm-tutorial](https://github.com/chuan2019/litellm-tutorial). Each edition has its own branch there, named `litellm-<version>`. Its [changelog](https://github.com/chuan2019/litellm-tutorial/blob/main/CHANGELOG.md) lists what changed in each release.
